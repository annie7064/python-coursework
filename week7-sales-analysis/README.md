# Sales Data Analysis Dashboard

A Python and Pandas data processing application designed to ingest raw sales datasets, clean missing/duplicate values, compute business intelligence metrics, and export reports and visualizations.

## Features
- Ingestion of CSV and Excel dataset sources.
- Automated data cleaning (duplicate removal, mode/median missing value imputation).
- Calculation of key performance metrics (revenue, order counts, monthly trends, top products).
- Automatic chart visualization generation (`.png`).
- Export of multi-sheet analytical Excel reports.
